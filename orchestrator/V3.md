# v3 video pipeline (reference-parity)

One click (control panel "Run render", or `make-video.js`) turns a topic into a finished,
gate-checked 1080x1920 short in the measured style of the reference reels. v1/v2 live in
`archive/legacy-v1-v2/` and are not used. Measurements behind every number:
`analysis/pacing-audit-20260924/design/SPEC.md` (+ per-video `design/R1..R5/AUDIT.md`).

```
node make-video.js --topic "How JWT authentication works" --out output/jwt.mp4 [--profile auto|DH|LC|DC] [--length-seconds 45] [--accent #4497ff]
```

## Flow

1. **Style** (`--profile auto`): Gemini picks DH / LC / DC for the topic.
   - DH dark dashboard (R1/R2): systems, incidents, traffic, deployments.
   - LC light editorial (R3/R4): building things step by step, dev tools, protocols.
   - DC dark chaptered (R5): what a company / platform actually does.
2. **Storyboard** (`lib/video/v3/storyboardGen.js`): Gemini writes storyboard.v3 from the profile
   grammar + card catalog (`catalog.js`) + a worked example (`fixtures/v3/*`). It is validated by the
   real compiler on synthetic timings (anchors, targets on screen, overflow), density and cadence
   bands; failures are fed back (up to 4 attempts), long-hold near-misses get deterministic emphasis beats.
3. **Voice**: persistent F5-TTS + WhisperX worker (`voiceService.js`), cached per sentence. Default voice is the
   consent-confirmed cloned `narrator` profile (`voice-pipeline/voices/narrator/`, gitignored wav, copied from
   script-to-video-pipeline); `--ref-audio/--ref-text` or the control-panel profile override it, `--voice-profile stock` uses F5's example.
4. **Timeline**: speed solved for ~212 wpm, 0.2 s sentence gaps, atempo BEFORE rendering (frames exact).
5. **Compile** (`compile.js` + `templates-*.js`): scaffolds of cards at measured rects, word-anchored events,
   profile chrome (HUD / header+counter / chapter+progress).
5b. **Layout audit** (`tools/layout_audit.js`, hard): headless Chrome seeks every scaffold and measures overlapping
   cards/nodes, text off the frame / outside its card / clipped / under the mascot, and renderer build errors.
   Runs inside the storyboard repair loop (synthetic timing) and again on the real timing before render.
5c. **SFX** (`lib/video/v3/sfx.js` + `tools/sfx_mix.py`): synthesized (no assets) tick / blip / pop / whoosh / swish /
   keys / roll / strike / chime cued on every visual change, ~19 LU under the voice, mixed before render. `--sfx false` disables.
6. **Render**: `video-engine/compositions/components/stage` + `lib/stage/*` (seek-safe GSAP), captions per
   profile skin, `hyperframes check` must pass.
7. **Master** to -14 LUFS, LRA <= 1.6, TP <= -1 dBTP (re-mastered with more headroom if AAC overshoots).
8. **Gates** (`tools/v3_gates.py`, hard): beats/min, longest hold, scene life, wpm, loudness, frame
   geometry. A storyboard-class failure is repaired by regenerating with the measured failure (2 rounds).

## Cards (lib/stage)

`modules-dh.js` HUD, label, router, lever, env card, users, headline, banner, pill ·
`modules-dh2.js` micro, title card, browser, console, option, stat, hero, chart, connector ·
`modules-dh3.js` panel, table, nodes (connectors, packets, lighting), kpis, code, compare, bars, steps, chips ·
`modules-dh4.js` stamp, timeline, layers, tree, note, letters, slot ·
`profile-lc.js` LC chrome (header, title, footnote, display) · `profile-dc.js` DC chrome (chapter, stage, serif hero).
Colours are theme variables (`theme-lc.js`, `HF.themes.DC`); motion uses only measured recipes.

## Dev tools

- `tools/v3-dryrun.js sb.json out.json` compile a storyboard on synthetic timings
- `tools/stage-preview.js --spec out.json --out dir --at 1,2.5 [--check]` snapshots / check without voice
- `tools/v3-storyboard.js "topic" out.json` storyboard only
- `tools/theme_vars.py` re-wrap card colours after adding CSS

## Known limits

- Mascot is the SpongeBob placeholder (user decision); proportions differ from the refs' presenters.
- No music bed (user decision; SFX only), so ~7% of 20 ms windows sit below -60 dBFS (refs 0.1-0.2%).
- DC hero serif uses Playfair Display (installed) condensed; bundle Instrument Serif for an exact match.
- Inter / IBM Plex Mono / Playfair are system-installed here; JetBrains Mono is bundled.
