# incognito storyboard (9:16, iso MG, voice at 1.3x)

Look: the approved colourful iso kit (mg/isokit) on the deep-indigo field. One world per card: small floating islands in a row, so it reads left to right on a phone
(phone -> router -> provider tower -> website). Glow only on emitters (packets, beams, wifi, rings). Ember only for "blocked / broken" (the cloak that cannot reach the school network).
Coral = a watcher or the record, mint = hidden here, saffron = the postman and names, violet = the Incognito hat.
Times are global episode seconds (words from shots.json; mg.js looks the words up at run time).
Sound-off test: every card has to show the mechanism moving, not a label.

Card layout (9:16 `float`): card x 54, y 154, 972 x 560. Heads clear (episodes/incognito/headcheck.js). Every text >= 28 px (hud 34 x .85). No card longer than ~7.5 s.
Cards enter and leave on the nearest shot cut. Under cards only MS/CU rigs (no wide2, high34, profile2, tent_wide, low_fire).
