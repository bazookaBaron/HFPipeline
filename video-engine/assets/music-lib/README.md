# Music library (free tracks, $0)

Long-form videos take their music from here: one track per section, switching every ~40–60 s at
section/scene boundaries (`orchestrator/lib/longform/musicPlan.js`). If this folder is empty, or no
track fits a mood, the pipeline falls back to the built-in synthesized beds (ambient / lofi / pulse,
picked by mood). Everything works before you download anything.

What to download: see [SHOPPING-LIST.md](SHOPPING-LIST.md).

## Folder layout

```
music-lib/
  tension/        investigative/   dread/      hopeful/
  playful/        calm/            triumphant/ trailer/   (montage: 95–125 BPM, heavy low end)
  sfx/            impacts/, risers/, whooshes/, sub-drops/ subfolders (optional)
  index.json      generated by music_index.py (git-ignored)
```

The folder name is the track's mood. Any of `.mp3 .wav .ogg .m4a .flac .aac .opus` works.
Audio files are git-ignored: they are downloaded by hand and never redistributed through the repo.

## Adding a track

1. Download the track by hand (automated scraping breaks these sites' terms).
2. Put it in the mood folder, e.g. `tension/Kevin_MacLeod-Some_Track.mp3`.
3. Add a licence note. **A track without one is never used.** Either:

   **a) A sidecar file** next to it, named `<file>.license.json` (for example
   `Some_Track.mp3.license.json`):

   ```json
   {
     "title": "Some Track",
     "artist": "Kevin MacLeod",
     "source": "incompetech",
     "url": "https://incompetech.com/music/royalty-free/...",
     "license": "CC BY 4.0",
     "credit": "\"Some Track\" Kevin MacLeod (incompetech.com). Licensed under Creative Commons: By Attribution 4.0 License http://creativecommons.org/licenses/by/4.0/",
     "energy": 4
   }
   ```

   **b) Or a row in a `LICENSES.md`** table in the same folder (or any parent folder up to `music-lib/`):

   ```
   | file | title | artist | source | url | license | credit |
   |---|---|---|---|---|---|---|
   | Some_Track.mp3 | Some Track | Kevin MacLeod | incompetech | https://... | CC BY 4.0 | "Some Track" Kevin MacLeod (incompetech.com) ... |
   ```

   Required: `license`, plus `source` or `url`. `credit` is copied verbatim into the video's
   `description.md` ("## Music") and `credits.txt`. If you leave it empty, one is generated as
   `Music: "Title" by Artist (Source), Licence URL`. Always paste the exact credit line the site asks for
   (YouTube Audio Library shows it under the track; incompetech gives it on the track page).
   `energy` (1–5) is optional and overrides the analysed value.
4. Run the indexer (the long-form `master` stage also runs it automatically, incrementally):

   ```
   python orchestrator/tools/music_index.py            # --force re-analyses everything
   ```

## What the indexer stores (`index.json`)

Per track, analysed locally with librosa: `bpm`, `beats`, `downbeats`, 4-bar `phrases`, `entry` (the
first full-energy downbeat, where the track starts when a section begins), `loop` (phrase-boundary loop
points for sections longer than the track), `rms` curve (dB, 2 Hz), `lufs`, `lowRatio` (share of energy
below 150 Hz), `onsetRate`, `energy` 1–5, `montageOk` (95–125 BPM, heavy low end), `usable` span, plus
`mood`, `license`, `licensed`, `credit`, `hash`/`size`/`mtime` (incremental re-runs skip unchanged files).
SFX get `sfxCategory`, `duration`, `peakAt`.

## How it is used

- **Plan** (`musicPlan.js`): script section `mood`/`energy` (or heuristics by chapter position) →
  one track per section, energy-matched, no repeats within a video, rotated across videos
  (`orchestrator/output/music-usage.json`). Mood fallback chain, e.g. dread → tension → investigative.
  `trailer` tracks are reserved for the cold-open montage (`pickTrailer()`, `beatGrid()`).
- **Mix** (`orchestrator/tools/sfx_mix.py --music-plan`, `music_switch.py`): each switch is a 2.5 s
  bass drop-out (rising high-pass) on the outgoing track, and the new track comes in on the cut, on a
  downbeat. Beds sit 12 dB under the voice in pauses and are ducked 10 dB more under speech (montage:
  −4 dB, no ducking). Chapter cards get a +3 dB swell. The master then brings the whole video to −14 LUFS.
- **Credits**: every used track's `credit` goes to `final/description.md` and `final/credits.txt`.
