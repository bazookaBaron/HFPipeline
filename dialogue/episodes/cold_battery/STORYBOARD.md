# cold_battery storyboard (9:16, colourful iso kit, "Thirty percent, then dead")

Look: the approved colourful iso kit (mg/isokit) on the deep-indigo field: mint islands, coral / saffron / sky / violet accents, glow ONLY on emitters
(the lit phone, the pulse rings, the lit charge cells). Ember is never used for a good state.
Colour code: cream = the lithium ions (the swimmers), sky = the thin liquid (normal), amber (saffron + soil) = the same liquid cold and thick ("honey"),
violet = the left electrode, mint = the right electrode / charge that is still there / safe, coral = demand, the voltage drop, "too slow", the shut-off.
One recurring object: the battery cell (two electrodes with a liquid trough between them). Every card re-uses it so the idea reads as ONE thing changing.
Each card is its own small floating world (island) and SHOWS the mechanism with the sound off. Times are global seconds of the 1.3x track
(mg.js looks words up with W(line, word)). Card layout (9:16 `float`): x 54, y 154, 972 x 560; heads clear (headcheck.js). Every tag/label >= 28 px
(hud size 34 x .85 = 28.9 px), at most ~3 words per tag, cards <= ~8 s, only MS/CU-type rigs under a card (no wide2 / high34 / profile2 / tent_wide / low_fire).
No label-only cards, no templates.js, no grey cubes, no stinger before the ending. L5 ("Swimming. Okay."), L7 ("Honey?"), L11, L15-L18 stay on the faces (no card).
